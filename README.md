# O ovom projektu
Ovaj projekat je urađen kao seminarski rad na fakultetu i u njemu se koristi neuronska mreža zasnovana na TensorFlow Keras biblioteci za klasifikaciju slika u dve kategorije: mačke i pse. Izrađen je u Google Colab okruženju.

## Korišćene tehnologije i alati

- Python
- TensorFlow / Keras biblioteka
- NumPy biblioteka
- Matplotlib biblioteka
- gdown biblioteka
- Razvojno okruženje Google Colab
  
# Korisničko uputstvo

### Pokretanje projekta

1. Otvoriti fajl  `KlasifikacijaSlikaProjekat.ipynb` u Google Colab-u

2. Pokrenuti sve ćelije (`Runtime->Run All`)

3. Sačekati da skripta preuzme podatke (`.csv` fajlove) i završi treniranje modela - vrši se automatski <br>*Napomena:* podaci se automatski preuzimaju sa Google Drive linkova pomoću `gdown` biblioteke

4. Nakon toga, može se prikazati slika za koju model predviđa da li je u pitanju pas ili mačka
